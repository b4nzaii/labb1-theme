# Mitt WordPress-tema – Labb 1

Temat är byggt från grunden och innehåller funktionalitet för undersidor, blogg, widgets, menyer, kontaktformulär och en responsiv, WCAG-anpassad design.

---

## Funktioner

- Egen front-page.php med hero-sektion + senaste inlägg
- Blogg (posts page)
- Single inlägg (single.php)
- Page-mallar för statiska sidor
- Fyra extra undersidor (Undersida 1–4)
- Egna menyer (huvudmeny)
- Sidebar-widgetområde
- Contact Form 7–formulär med SMTP (Brevo)
- WCAG-godkänd färgpalett
- Responsiv design (mobil och desktop)
- Temats egna CSS-design (style.css)
- Användarroller testade: Admin, Editor, Author
